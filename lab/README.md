# Glagol Design Lab · v3.0.0

Живая страница, на которой видно действующую дизайн-систему, реальные экраны
бюро и три концепции «Глагола 2.0».

**Опубликовано:** https://claude.ai/artifact/RECS5xUyJpuS4b3RFfSZr5

Концепции открываются своими адресами:

| | Адрес |
| --- | --- |
| A · Инструмент | https://claude.ai/artifact/RECS5xUyJpuS4b3RFfSZr5/concept-a.html |
| B · Мастерская | https://claude.ai/artifact/RECS5xUyJpuS4b3RFfSZr5/concept-b.html |
| C · Маршрут | https://claude.ai/artifact/RECS5xUyJpuS4b3RFfSZr5/concept-c.html |

Страница приватная: открывается у владельца и у тех, кому он дал доступ.
Поделиться — через меню «Поделиться» на самой странице.

## Из чего собрана

| Файл | Что это |
| --- | --- |
| `index.html` | витрина: разделы А (система), Б (реальные экраны), В (концепции) |
| `concept-a/b/c.html` | самостоятельные страницы концепций |
| `tokens.css` | **сгенерирован** из `app/globals.css` |
| `work.css` | **сгенерирован**: копия `app/work.css` байт в байт |
| `lab.css`, `lab.js` | мебель витрины: шапка, переключатели, полки |
| `shots/` | снимки Playwright, 1440 и 375, светлая и тёмная |

`tokens.css` и `work.css` руками не правятся: их собирает `node lab/build.mjs`
из настоящего кода продукта. Поэтому Lab не может разойтись с системой —
он ею и собран.

**Исключение, и оно названо на самой странице:** примитивы `components/ui/` —
это React, и в статической странице без сборки они не живут; здесь показан их
вид на тех же токенах. Раскладку в продукте задают утилиты Tailwind, которых
здесь тоже нет, поэтому композиция разделов и концепций написана своим CSS.

## Как обновить

```bash
npm run lab      # пересобрать стили из продукта, переснять и проверить
```

Потом опубликовать тот же `lab/index.html` поверх существующего адреса — URL
сохранится.

Скрипт съёмки берёт Playwright у атласа (`~/dev/glagol-atlas`): второй
установки браузера в бюро не заводим. Экраны дизайн-системы снимаются с
`localhost:3031` — поднимите `npm run dev` перед съёмкой или добавьте
`--no-ds`.

## Что проверяется съёмкой

Каждая страница в четырёх видах — 1440 и 375, светлая и тёмная, — и на каждой:

- горизонтальная прокрутка страницы;
- область касания меньше 44 у кнопок, ссылок и пунктов меню;
- ошибки в консоли;
- подхватились ли шрифты бюро.

Итог ложится в `shots/ОТЧЁТ.txt`. Грепом это не измерить — поэтому
`ui-guard` ловит причину (жёсткая ширина, нативное поле, таблица без
мобильного вида), а съёмка ловит симптом.

## Границы

Концепции — экспериментальные. Их композиционные приёмы и локальные токены
живут только здесь и системные не замещают. Переносить что-либо из них в
рабочий интерфейс до выбора направления нельзя.

Все данные на экранах синтетические: настоящих людей, клиентов, встреч и
закрытых методик здесь нет.
