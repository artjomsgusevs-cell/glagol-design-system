# Проверки и приёмка

Свод без падающей команды через месяц становится украшением — это уже
проверено на мёртвых разделах v1.31. Поэтому у каждого правила, которое можно
проверить машиной, есть строка в стороже.

## Чем проверяем

| Команда | Что делает | Держит выкатку |
| --- | --- | --- |
| `npm run check` | гоняет всё ниже и показывает долг одной сводкой | — |
| `tsc --noEmit` | типы | да |
| `ui-guard.mjs` | список конкретных грабель, греп, доли секунды | нет, советует |
| `blocked-hosts.mjs` | показ страницы не зависит от чужого сайта | да |
| `sync-design` | эталон не разошёлся с продуктом | нет, советует |

Сторож живёт в календаре (`glagol-calendar/scripts/ui-guard.mjs`) и зовётся
соседними проектами по относительному пути: один список правил на все
продукты, иначе разъедутся и продукты.

Ложное срабатывание глушится комментарием строкой выше, и только с причиной:
`{/* ui-guard-ignore: подпись не меняет высоту, проверено */}`. Без причины
глушить нельзя — правило перестанет что-либо значить.

## Адаптивные правила сторожа

Заведены в v3.0.0, потому что требование от 01.11.2026 прозвучало дважды, а
что прозвучало дважды — становится проверкой:

- **горизонтальная прокрутка на 375** — страница не шире окна;
- **область касания 44×44** у кнопок, пунктов меню и строк списка, с учётом
  предусмотренных системой исключений;
- **таблица без мобильного представления** — либо плитки, либо своя
  прокрутка;
- **нативные `date` и `select`** — запрещены;
- **`flex-1` с фиксированной высотой в колонке** — было и раньше, это
  образцовый пример того, как мобильный баг становится правилом.

## Снимки экранов

`glagol-atlas` — Playwright и pixelmatch. Каждый экран снимается в четырёх
видах: **телефон 375 и десктоп 1280 × светлая и тёмная.** Меньше нельзя:
половина расхождений живёт именно в тёмной теме и в мобильной раскладке, а
смотрим мы обычно светлую на большом мониторе.

```bash
cd ~/dev/glagol-atlas
npm run shot      # снять
npm run diff      # что изменилось против эталона
npm run accept    # принять новые снимки эталоном
```

До правки — `shot` и `accept`, после — `shot` и `diff`: он покажет и те
экраны, которых не трогали.

**`accept` не запускается не глядя.** Принятый вслепую снимок узаконивает
ошибку, и регрессионная проверка начинает защищать именно её. Смотрим diff
глазами, потом принимаем.

Экраны дизайн-системы и Design Lab входят в атлас своей секцией. Эталоны
концепций лежат отдельно от эталонов продукта: концепции меняются часто, и
смешивать их с продуктовой базой нельзя.

## Что смотрим глазами

Команда ловит грабли, а не качество. На 375 и 1280, в обеих темах:

- **композиция** — видно, что здесь главное, с первого взгляда;
- **иерархия** — кеглей не больше трёх, и каждый означает своё;
- **читаемость** — подписи не мельче 11, текст не сливается с фоном;
- **доступность действий** — главное действие видно без прокрутки;
- **плотность** — на компьютере нет пустых полей шириной в полэкрана, на
  телефоне ничего не прилипло к краю;
- **ничего не скачет** — замер `getBoundingClientRect()` до и после действия.

Проверка — `.claude/skills/glagol-visual-review/SKILL.md`: он ссылается на эти
документы и работает как независимый критик. Он не заменяет просмотр человеком:
последнее слово за Артёмом.

## Критерий готовности

«Готово» — только про то, что воспроизвели: «нажал X → увидел Y». Не
проверяли — пишем «не проверяли». Функция, не открытая на телефоне, не принята.
