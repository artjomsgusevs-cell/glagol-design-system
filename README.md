# Glagol Design System

**Версия 3.0.0.** Канонический номер — поле `version` в `package.json`.
Единственный. Если где-то в документах встретилась другая цифра — это опечатка,
и права `package.json`.

Свод правил вида бюро Глагол и витрина живых элементов продукта.

> **Новое — целиком по стандарту 01.11.2026. Работающее не переделываем.**
> Включается атрибутом `data-ds="3"` на корне экрана или блока; слой
> `app/ds3.css` действует только внутри. Правило целиком —
> [`RULES.md`](RULES.md), раздел «Постепенная миграция»; причины решений —
> [`review/РЕШЕНИЯ.md`](review/РЕШЕНИЯ.md).

Чем этот репозиторий **не** является: местом, где рождается интерфейс.
Компоненты в `components/booking/` и `app/work.css` — копии из календаря, они
приезжают командой `npm run sync-design -- --write`, запущенной в календаре.
Править их здесь бессмысленно: при следующем переносе правка исчезнет.

## С чего начинать

| Файл | Когда открывать |
| --- | --- |
| [`RULES.md`](RULES.md) | всегда. Обязательное всем, источники истины, разрешение противоречий |
| [`docs/DESIGN.md`](docs/DESIGN.md) | новый экран или блок: визуальный язык, публичная и рабочая среды |
| [`docs/COMPONENTS.md`](docs/COMPONENTS.md) | собираешь экран: что уже есть, высоты, радиусы, кнопки, поля |
| [`docs/ADAPTIVE.md`](docs/ADAPTIVE.md) | всегда, когда есть раскладка: у каждого паттерна два ответа |
| [`docs/CHECKS.md`](docs/CHECKS.md) | перед показом работы |
| [`CHANGELOG.md`](CHANGELOG.md) | что изменилось в 3.0.0 и почему |
| [`ПЕРЕДАЧА.md`](ПЕРЕДАЧА.md) | начинаешь продуктовую работу: что подключать, как сделать первый экран, что проверить при интеграции |
| [`review/РЕШЕНИЯ.md`](review/РЕШЕНИЯ.md) | правило кажется придиркой: причины и отвергнутые варианты |

[`docs/archive/`](docs/archive/) — своды v1.31 и v2. **Не действующие правила**,
а происхождение приёмов: по ним видно, после какой поломки появилось каждое.
Значения оттуда брать нельзя, часть разошлась с кодом.

[`docs/АНАЛИЗ.md`](docs/АНАЛИЗ.md) — разбор, по итогам которого собрана 3.0.0.

## Команды

```bash
npm run dev      # локальный сервер, порт 3031 (.claude/launch.json)
npm run check    # типы, сторож вёрстки, сверка с продуктом
npm run lab      # Design Lab: снимки и проверки, см. lab/README.md
```

## Контрольный экран

[`lab/новый-экран.html`](lab/новый-экран.html) — страница, собранная по
стандарту и ничего не изобретающая: в её собственном `<style>` только
раскладка, все значения приходят из `tokens.css`, `work.css` и `ds3.css`.
Проверка `lab/shoot.mjs` это и сторожит. Если новый приём системы негде
показать — его место здесь.

## Design Lab

`lab/` — отдельная страница, на которой видно действующую систему, реальные
экранные паттерны и три концепции «Глагола 2.0». Публикуется как артефакт;
ссылка и порядок обновления — в [`lab/README.md`](lab/README.md).

Lab берёт настоящие `app/work.css` и настоящие значения токенов из
`app/globals.css`, а не свои копии.
