# Дизайн-система бюро

Общие правила работы — в `../CLAUDE.md`. Здесь то, что своё.

## Чем этот проект является

Сводом правил вида — `RULES_v1.31.md` — и витриной живых элементов продукта.

Чем он **не** является: местом, где рождается интерфейс. Компоненты в
`components/booking/` — копии из календаря, они попадают сюда командой
`npm run sync-design -- --write`, запущенной в календаре. Править их здесь
бессмысленно: при следующем переносе правка исчезнет.

Если эталон и продукт разошлись — прав продукт, а эталон отстал. 30 июля они
разошлись по трём файлам, и страница эталона четверо суток показывала кнопку с
обводкой, которой в проде нет.

## Команды

```bash
npm run dev      # локальный сервер, порт 3000
npm run check    # типы, вёрстка, сверка с продуктом
```

## Что помнить

- `components/ui/` — дамп shadcn на 60 файлов, из которых используется 18.
  Остальные не проверяются и палитре бюро не соответствуют. Брать оттуда
  что-то новое — сверять с `RULES_v1.31.md`.
- Токены в `app/globals.css`. Второй файл токенов со стоковой серой палитрой
  здесь однажды уже лежал ловушкой — не заводить снова.
